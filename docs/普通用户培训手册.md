## 1. 登录平台

### 1.1 访问地址

- 公司部署地址：（请联系 IT 同事获取）

### 1.2 使用固定账号登录

> 📌 **不要自行注册账号！** 平台账号由管理员统一开通，请使用分配给你的 **固定账号** 登录。

1. 打开浏览器（推荐 Chrome / Edge），访问公司部署地址。
2. 在登录页填写 **管理员分配给你的账号和密码**：
   - 账号：通常是工号 / 邮箱 / 企业微信 ID（具体以管理员通知为准）。
   - 初始密码：管理员会在开通账号时一并告知，**首次登录后请立即修改密码**。
3. 点击 **"登录"** 进入平台。

> 如忘记密码、账号被锁定、登录失败等，请联系 IT 管理员处理，**不要自行注册**。

### 1.3 主界面三个常用入口

登录后会看到左侧导航栏，本手册重点教你使用下面三个入口：

| 入口 | 用途 | 对应章节 |
|------|------|----------|
| **对话** | 输入问题，AI 从知识库找答案 | 第 4 章 |
| **知识库** | 上传 / 编辑 / 管理文档 | 第 2、3 章 |
| 设置 | 修改密码、个人信息 | 按需 |

## 2. 知识库上传：让文档可以被检索

> 🎯 **核心目的**：把公司现有文档（Word、PDF、Excel 等）放到平台上，让员工提问时可以被检索到。

### 2.1 支持的文档格式

| 类别 | 格式 |
|------|------|
| 文档 | PDF、Word（doc/docx）、EPUB、HTML |
| 表格 | Excel（xls/xlsx）、CSV |
| 演示 | PowerPoint（ppt/pptx） |
| 文本 | TXT、Markdown（md）、JSON、XML |
| 图片 | JPG、PNG、GIF、BMP、WebP |
| 音频 | MP3、WAV、M4A、FLAC、OGG、AAC |

### 2.2 上传文件时的编写模板（重要）

> 📌 **为什么需要模板？** 平台会按文档的结构来"理解"内容。**结构越清晰，回答越精准**。下面 4 个模板可直接套用。

#### 模板 A：产品手册 / 操作指南（Word / Markdown）

```markdown
# 产品操作手册

> 版本：v2.3 · 适用于产品 A 1.5.0 及以上
> 更新日期：2025-09-12
> 适用对象：客服、销售、实施工程师

## 1. 快速开始

### 1.1 系统要求
- 操作系统：Windows 10/11、macOS 12 及以上
- 浏览器：Chrome 100+ / Edge 100+

### 1.2 首次登录
1. 打开浏览器，访问 https://example.com
2. 输入工号与初始密码
3. 首次登录会强制修改密码

## 2. 账户管理

### 2.1 如何修改密码？
- 进入"个人中心 → 安全设置 → 修改密码"
- 输入旧密码、新密码、确认新密码
- 点击"保存"后会强制重新登录

### 2.2 忘记密码怎么办？
- 点击登录页"忘记密码"链接
- 输入注册邮箱，系统会发送重置邮件
- 邮件 30 分钟内有效

## 3. 常见问题 FAQ

### 3.1 登录时提示"账号被锁定"？
连续输错密码 5 次会锁定 30 分钟。请联系管理员解锁。

### 3.2 上传文件失败？
- 检查文件大小是否超过 100 MB
- 联系管理员查看存储配额
```

**编写要点**：

- 一级标题 `#`，二级 `##`，三级 `###`，**层级清晰便于检索**。
- 每个章节聚焦一个主题。
- **用疑问句作小标题**（如"如何修改密码？"），直接命中用户提问。
- 文档开头写明 **版本、适用对象、更新日期**。

#### 模板 B：政策 / 制度文件（PDF / Word）

```markdown
# 员工差旅报销管理办法

## 第一条 目的
为规范员工差旅报销流程，加强费用管控，特制定本办法。

## 第二条 适用范围
适用于公司全体正式员工、试用期员工。

## 第三条 报销标准

### 3.1 交通费
| 职位 | 飞机 | 火车 |
|------|------|------|
| 高管 | 商务舱 | 高级软卧 |
| 普通员工 | 经济舱 | 二等座 |

### 3.2 住宿费
- 一线城市：≤ 800 元/晚
- 二线城市：≤ 600 元/晚

## 第四条 报销流程
1. 出差结束 5 个工作日内提交报销单
2. 部门负责人审批（1 个工作日）
3. 财务复核（2 个工作日）

## 第五条 常见问题

### 5.1 临时改签产生的费用能否报销？
可以，但需提供改签凭证，且改签理由须合理。

### 5.2 同行人员垫付的费用如何处理？
由其中一人统一报销，其余人员提供"费用说明"作为附件。
```

**编写要点**：

- 使用"第 X 条"等正式编号，便于回答时引用。
- 涉及金额、时限的数字建议放在表格里。
- **末尾用 FAQ 章节收口**，把大家实际工作中常问的细节问题写清楚。

#### 模板 C：会议纪要 / 项目记录

```markdown
# XX 项目启动会会议纪要

- 时间：2025-09-15 14:00-16:00
- 地点：总部 305 会议室
- 与会人：张三（PM）、李四、王五（研发）

## 议程与决议

### 1. 项目目标
Q3 末完成 MVP 上线，覆盖核心 3 个业务场景。

### 2. 关键里程碑
- 9/30：完成需求评审
- 10/15：完成技术方案
- 11/30：MVP 上线

### 3. 风险与对策
| 风险项 | 负责人 | 应对方案 |
|--------|--------|----------|
| 第三方接口未确定 | 李四 | 9/25 前完成 POC |

## 待办事项
- [ ] 张三：9/18 前输出 PRD 初稿
- [ ] 李四：9/20 前完成技术选型报告
```

**编写要点**：

- 文档开头写明时间、地点、参与人，便于回答时给出背景。
- 决议、待办、风险用专门的小标题清晰区分。
- 每个待办指定明确负责人。

#### 模板 D：Excel / CSV 表格

```
建议结构：
├─ 第 1 行：标题（如"产品参数表 2025 版"）
├─ 第 2 行：表头（如"产品名称 | 型号 | 价格 | 上市时间"）
├─ 第 3 行起：每行一条记录
└─ 表格下方留空 1 行，写一段"说明"
```

> 单个 Excel 建议 ≤ 200 行，多则拆成多个小表。

### 2.3 上传操作步骤

1. 点击左侧 **"知识库"**。
2. 选择要上传到的目标知识库（管理员会告诉你该传到哪个知识库）。
3. 在知识库页面点击 **"上传文件"** 按钮。
4. 选择本地文件（可一次选多个）。
5. 弹出"上传配置"对话框，**普通用户保持默认即可**，直接点 **"确认"**。
6. 上传完成后，文档进入 **"待解析 → 解析中 → 已完成"** 流程，通常几分钟即可被检索。

> 💡 **解析状态说明**：
> - 待解析 / 解析中：等待系统处理。
> - 已完成：可以被检索。
> - 失败：可点击"重新解析"重试。

## 3. 知识库编辑：在平台上直接编写

> 🎯 **适用场景**：公司制度没有现成文档；临时通知；快速录入 FAQ；你想直接在平台上沉淀一份知识。

### 3.1 Markdown 速查表

平台编辑器使用标准 Markdown 语法，下表覆盖 90% 的常用写法：

| 用途 | 写法 | 效果 |
|------|------|------|
| 一级标题 | `# 标题` | 大号标题 |
| 二级标题 | `## 标题` | 中号标题 |
| 加粗 | `**文字**` | **文字** |
| 斜体 | `*文字*` | *文字* |
| 无序列表 | `- 项目` | • 项目 |
| 有序列表 | `1. 项目` | 1. 项目 |
| 任务列表 | `- [ ] 待办` | ☐ 待办 |
| 链接 | `[文字](https://...)` | 可点击链接 |
| 图片 | `![说明](url)` | 显示图片 |
| 引用 | `> 内容` | 引用块 |
| 行内代码 | `` `代码` `` | 代码样式 |
| 代码块 | ` ```代码``` ` | 多行代码 |
| 分隔线 | `---` | 一条横线 |

**表格写法**：

```markdown
| 列 1 | 列 2 |
|------|------|
| A    | B    |
| C    | D    |
```

### 3.2 在平台直接编写时的模板（重要）

> 直接复制下面的模板 → 在平台上"粘贴 → 改标题 → 改内容 → 发布"，几分钟就能写出一份高质量知识。

````markdown
# 【文档标题】一句话说明这是什么

> 文档版本：v1.0 · 适用对象：XX 部门 · 更新日期：2025-09-15

## 一、背景 / 概述
（2-3 句话讲清楚这份文档要解决什么问题、给谁用）

## 二、核心内容

### 2.1 小节标题 A
（写具体的知识点、流程、规范）

### 2.2 小节标题 B
（表格 / 列表 / 步骤）

## 三、操作步骤（如适用）
1. 第一步：……
2. 第二步：……
3. 第三步：……

## 四、常见问题

### 4.1 如何 XXX？
回答要点 1、要点 2、要点 3。

### 4.2 XXX 失败了怎么办？
回答要点。

## 五、相关链接 / 参考
- [相关制度一](url)
- [相关工具说明](url)
````

**常用模板速查**（按场景复制粘贴）：

**① 操作指南**

```markdown
# [操作名称]

> 适用对象：XX · 预计耗时：X 分钟

## 前提条件
- 条件 1
- 条件 2

## 操作步骤
1. 步骤一
2. 步骤二
3. 步骤三

## 结果验证
如何确认操作成功。

## 异常处理
| 异常现象 | 解决方案 |
|----------|----------|
| …… | …… |
```

**② FAQ 条目**

```
【标准问】如何 XXX？
【相似问】怎么 XXX？XXX 怎么办？
【答案】
1. 第一步
2. 第二步
【标签】XX
```

**③ 制度文件**

```markdown
# [制度名称]

## 第一条 目的
…

## 第二条 适用范围
…

## 第三条 ……

## 附则
- 解释权归属
- 生效日期
```

### 3.3 保存草稿与发布

平台编辑器底部有三个按钮：

| 按钮 | 作用 |
|------|------|
| **保存草稿** | 保存为草稿状态，**不会被检索**。适合反复修改。 |
| **取消** | 不保存，关闭编辑。 |
| **发布** | 正式生效，**自动触发解析、进入检索库**。要求内容 ≥ 10 字。 |

> 📌 发布后仍可继续编辑，每次重新发布都会重新解析（异步进行，不影响阅读）。

## 4. 知识库查询：让 AI 帮你找答案

> 🎯 **核心目的**：员工通过自然语言提问，AI 自动从知识库中找到相关内容并给出带原文引用的回答。

### 4.1 进入对话与选择知识库

1. 点击左侧 **"对话"** → 点击 **"新建对话"**。
2. 在对话窗口顶部会显示 **"选择知识库"** 下拉框，点击选择你要查询的知识库（可多选；不选则使用默认）。
3. 在底部输入框输入问题，回车即可。

### 4.2 提问模板（让回答更准）

| 场景 | 推荐提问 | 不推荐提问 |
|------|----------|------------|
| 查流程 | `请说明 XX 的具体流程，按步骤列出` | `怎么弄？` |
| 查政策 | `公司对 XX 的最新政策是什么？包括哪些例外情况？` | `那个事` |
| 查标准 | `XX 在不同场景下的标准分别是多少？请用表格列出` | `标准多少` |
| 找资料 | `请找一份关于 XX 的文档，要求包含示例代码` | `找一下` |
| 比较差异 | `请对比 A 和 B 的区别，用表格展示` | `哪个好` |

**提问小技巧**：

1. **包含场景**：`生产环境下的部署步骤` 比 `怎么部署` 更精准。
2. **用文档里出现过的原词**：如果文档叫"差旅报销"，提问时也用"差旅报销"，比"出差费用"更易命中。
3. **分多次追问**：复杂问题拆成几步追问，AI 更易准确回答。
4. **@提及知识库**：输入 `@`，可弹出知识库/文件列表，选中后提问只在该范围内检索。

### 4.3 阅读回答与引用

回答区下方有几个常用功能：

- **引用脚注**（如 [1][2]）：点击可跳转到原文出处，**用来校验是否相关**。
- **参考面板**（右上角）：列出所有被引用的原文片段。
- **推荐问题**：回答下方会显示 2-3 个相关追问，点击可一键继续。
- **重新生成**：重新跑一遍，得到不同措辞的回答。
- **点赞 / 点踩**：点赞帮助系统学习，点踩反馈不准确回答。

> 📌 **如果回答"找不到相关内容"**：尝试用文档中出现的原词提问，或检查所选知识库是否正确。

## 5. 常见问题

### 5.1 登录类

| 问题 | 排查 |
|------|------|
| 忘记密码 | **不要自行注册**，联系 IT 管理员重置。 |
| 账号被锁定 | 通常是连续输错密码导致，请联系 IT 管理员解锁。 |
| 登录失败，提示账号不存在 | 确认账号已由 IT 管理员开通，并使用正确的账号登录。 |

### 5.2 上传 / 解析类

| 问题 | 排查 |
|------|------|
| 上传失败，提示"文件太大" | 单文件 ≤ 100 MB，压缩或拆分后重试。 |
| 解析一直停在"解析中" | 后端可能积压任务；可在文档菜单点"取消解析"后重试。 |
| PDF 解析乱码 | 可能是扫描件（图片），联系管理员启用多模态识别。 |
| 上传后查不到内容 | ① 文档是否已完成解析 ② 提问时是否选对知识库 ③ 关键词是否与文档一致 |

### 5.3 编辑类

| 问题 | 排查 |
|------|------|
| Markdown 表格不显示 | 检查列对齐符号 `\|--- \|` 是否正确。 |
| 在线录入按钮灰色 | 当前知识库不支持在线录入，请改用上传文件方式。 |
| 发布失败，提示内容太短 | 内容需 ≥ 10 字。 |

### 5.4 查询类

| 问题 | 排查 |
|------|------|
| 回答"找不到相关内容" | 尝试用文档中出现的原词提问，或换一个知识库。 |
| 回答不准确 | 文档结构或表述不清晰，按第 2.2 节的模板重新整理后重新解析。 |
| 引用链接打不开 | 检查 KB 中该文档是否已被删除。 |
